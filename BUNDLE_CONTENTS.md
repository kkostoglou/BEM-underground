# GitHub repository contents

Included: Python solver and GUI, Windows launcher, installation and user guides,
Conda environment and Python package metadata, maintained and historical DAT
inputs, original Fortran source and disk material, Introduction PDF, full thesis
PDF, original drawings, thesis-figure index PDF, Appendix F checking guidance,
and formulation and historical validation notes.

Excluded by `.gitignore`: local Python environments, caches, build products,
local credentials, generated NPZ archives and PDF reports under `examples/results/`,
and the `github-upload/` export directory. Existing local results are preserved.

This checkout does not contain the `validation/` scripts or reference data,
separate chapter PDFs under `Documentation/parts/`, or the historical Word
files mentioned in earlier bundle descriptions. Read the complete thesis for
Chapter 5, Chapter 6, and Appendix F. Historical validation notes may refer to
files from the original working project that are not included here.

No reuse license has been selected for the Python code, original Fortran
material, or documents. No license grant is implied by publishing this folder.

Follow GITHUB_UPLOAD.md to publish the source tree. A ZIP uploaded as a single
repository file does not make its contents browsable as source.
